What I've Built.

01

VitalSync — Health Monitoring System

Wall-powered IoT health station on ESP32 measuring heart rate, SpO₂ & body temperature via MAX30102 and DS18B20. Custom BPM peak-detection (EMA) and Maxim's ratio-of-ratios SpO₂ algorithm over 100-sample rolling buffer.

Non-blocking firmware with millis()-based timers, OLED auto-rotate, MQTT/TLS cloud sync to Arduino IoT Cloud, and hand-soldered 6×4 perfboard with regulated 12V→5V→3.3V power chain (LM2596 + AMS1117). Project showcase site deployed via GitHub Pages.
